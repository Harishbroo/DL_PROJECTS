# Deep Learning Projects Portfolio

Welcome to my Deep Learning repository! This portfolio contains a collection of deep learning projects focusing on neural networks, computer vision, natural language processing, and transfer learning.

## 📁 Repository Structure

Each folder in this repository represents a standalone deep learning project. Inside each folder, you may find:

- **Jupyter Notebooks (`.ipynb`)** – Model development, training, and evaluation.
- **Python Scripts (`.py`)** – Model implementation and prediction.
- **Trained Models** – Saved models used for inference and deployment.
- **Streamlit Applications (`app.py`)** – Interactive applications for model predictions.
- **Docker Support** – Dockerfile and requirements for containerized deployment.
- **Project READMEs** – Documentation describing the project's objective, workflow, and results.

## 🛠️ Tech Stack & Core Tools

- **Programming Language:** Python
- **Libraries:** TensorFlow, Keras, NumPy, Pandas, Matplotlib
- **Models & Techniques:** ANN, CNN, RNN, LSTM, Transfer Learning
- **NLP Tools:** Hugging Face Transformers
- **Web Framework:** Streamlit
- **Deployment:** Docker, Render
- **Version Control:** Git, GitHub
- **Development Environment:** Google Colab, Jupyter Notebook, VS Code
